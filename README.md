# AI 校园社区 · 一站式服务站

网站地址：https://uluuluu.github.io/ai-campus-community/

每日 AI 资讯、Prompt 模板库、新人上手路径与产品反馈。

## 下次从这里继续

- 已完成：网站文件已上传，GitHub Pages 已配置从 `main` 分支根目录自动发布。
- 访问验收：浏览器公开访问与手机微信内访问分别验证；微信内访问仍需真实设备测试。
- 若更新日报：编辑 `assets/data/reports.js`，将新一期放在列表前面并保持现有字段结构，提交后等待 Pages 部署完成。
- 完成标志：打开网站，“最新日报”展示新一期，日报详情链接可以正常进入。

## 文件位置

- `index.html`：网页入口。
- `style.css`：样式与手机布局。
- `script.js`：导航、页面渲染、分类和复制交互。
- `assets/data/modules.js`：模块导航。
- `assets/data/reports.js`：日报内容。
- `assets/data/prompts.js`：Prompt 模板。

本项目是静态网站，无需安装依赖或执行构建。不要上传账号密钥、私人资料或无关文件。
